# SUNDB

SUNDB is a modular, independent database engine designed around the principles described in the master technical specification.

## Workspace structure

This repository is organized as a Rust workspace with separate crates for kernel, storage, query, transaction, indexing, security, networking, distributed systems, AI, CLI, and server runtime.

## Build and test

```bash
cargo test --workspace
```

## Initial status

This is the initial implementation scaffold and is intended as a starting point for engineering work rather than a production-ready database.
